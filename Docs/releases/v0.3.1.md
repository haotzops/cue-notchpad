# Cue Notchpad v0.3.1

## 变更

- 发布构建统一为 arm64。
- 开发构建、Release 预检与正式发布使用明确区分的 Make 入口，所有 app 默认目标均为 arm64。
- Release 归档改为 `Cue-Notchpad-0.3.1-macOS-arm64.zip`，并附带 `PROVENANCE.json`。
- 发布资产在公开前校验 GitHub digest，并由同一资产自动生成 Homebrew Cask 更新。
- 可下载、校验并安装指定公开 Release，用于精确复现用户问题。

## 安装

```bash
brew install --cask haotzops/tap/cue-notchpad
```

本版本需要 macOS 13 或更高版本，使用 ad-hoc 签名，未经过 Apple 公证。
