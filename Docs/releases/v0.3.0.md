# Cue Notchpad v0.3.0

本版本引入 DeepSeek AI 能力，并强化编辑安全、设置管理和发布验证。

## 主要更新

- **DeepSeek 行间补全**：可选自动或手动触发，支持流式建议、IME 保护、异步取消、模型选择和用量统计；功能默认关闭。
- **AI 重写**：可为当前 prompt 选择模型和提示词，通过快捷键请求重写并扩展。
- **数据与设置管理**：设置分为通用、AI、使用统计和快捷键页面；支持显式还原应用设置、清除使用统计和 API Key 管理。API Key 保存在用户专属的 `~/Library/Application Support/Cue Notchpad/config.json`，权限为 `0600`。
- **编辑安全**：文件写回前检查文件是否被其他进程修改，并以原子方式替换；IPC socket 竞争和请求校验更加严格。
- **编辑体验与分发**：优化编辑器随内容增长、品牌标识、调用方识别、token 不可用时的降级显示，并补充持久化兼容性、Universal app 和签名验证测试。
- **Pi 集成**：提供显式 `/cue` 扩展，将用户确认后的内容作为 follow-up 发送；不会自动发送会话内容。

## 兼容性与隐私

需要 macOS 13 或更高版本。DeepSeek 功能默认关闭；启用后，光标附近的 prompt 文本会发送到 DeepSeek API，并可能产生账户费用。API Key 不会写入 UserDefaults。

此版本使用 ad-hoc 签名，未经过 Apple 公证。手动安装时，请只在确认下载来源可信后，前往“系统设置 → 隐私与安全性”选择“仍要打开”。

## 安装与校验

推荐使用 Homebrew：

```bash
brew install --cask haotzops/tap/cue-notchpad
```

也可下载本 Release 中的 Universal ZIP，将 `Cue Notchpad.app` 移到 `~/Applications`，并按照 README 的 GitHub Release 安装说明创建 `cue` 启动脚本。

将 ZIP 和 `SHA256SUMS` 下载到同一目录后运行：

```bash
shasum -a 256 -c SHA256SUMS
```
