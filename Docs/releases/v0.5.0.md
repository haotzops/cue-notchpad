# Cue Notchpad v0.5.0

本版本集中更新 Provider 配置、使用统计和安装更新安全性，并将最低系统要求提升至 macOS 26+。

## 新增

- 支持多 Provider 配置 profile、自定义 API、模型 endpoint 和余额检测。
- 重新设计设置窗口，补充 Provider 诊断状态。
- 使用统计支持按天、按周和按月查看，并可浏览历史周/月周期。

## 变更与修复

- 历史周/月统计按每天显示完整柱状图；未结束的当前周期只显示截至今天的数据。
- 安装或升级时检测活动中的 `cue-host` 编辑会话，避免覆盖正在使用的编辑器进程。
- 内置 AI Provider 收敛为 DeepSeek、OpenAI 和 Anthropic，其他服务通过自定义 API profile 接入。
- API Key 改为按 profile 保存在本地配置文件，不再从环境变量读取供应商凭据。
- 修复 DeepSeek 余额接口字符串金额解析和货币字段读取问题。
- 更新 `config.json` Provider key 格式，并兼容旧版 DeepSeek 配置自动规范化。

## 兼容性

需要 macOS 26 或更高版本，仅支持 Apple Silicon（arm64）。当前发行使用 ad-hoc 签名，未经过 Apple 公证。

## 安装与校验

推荐使用 Homebrew：

```bash
brew install --cask haotzops/tap/cue-notchpad
```

也可下载本 Release 中的 `Cue-Notchpad-0.5.0-macOS-arm64.zip`，并使用随附的 `SHA256SUMS` 校验下载内容：

```bash
shasum -a 256 -c SHA256SUMS
```

完整安装与配置说明见 [README](../../README.md)。
