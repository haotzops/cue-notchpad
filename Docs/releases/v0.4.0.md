# Cue Notchpad v0.4.0

本版本将 AI 能力收敛为用户明确触发的重写，并扩展为多 Provider；同时重构设置、使用统计与 Pi 集成。

## 主要更新

- **多 Provider AI 重写**：支持主流开放 API、平台/网关、本地推理服务和自定义 Provider；各 Provider 独立保存凭据、模型与 endpoint，可直接输入模型 ID 或刷新本地服务模型。
- **Pi `${message}` 上下文**：由 Pi 打开的 Cue 可在重写提示词中使用 `${message}`，注入当前 active branch 最近一个 assistant turn 的文本。该文本只存在内存中，且只有用户明确触发包含该变量的重写时才会发送给所选 Provider。
- **设置与统计**：新增供应商凭据页，重构 AI、快捷键和使用统计页面；统计支持日期范围、摘要、活动趋势与明确的数据清除入口。
- **Pi integration 管理**：可在设置中显式安装、修复或卸载 Cue 管理的 Pi integration，并复制 `externalEditor = "cue --wait"` 配置；Cue 不会修改 Pi 的 `settings.json`。
- **窗口体验**：主窗口默认尺寸调整为 600×150，支持底边自由拉伸和锁定窗口设置。

## 不兼容变更

移除了 DeepSeek FIM 行间补全、ghost text、自动/手动触发、Tab 接受及相关快捷键。AI 功能现仅提供用户显式触发的 Chat Completion 重写；历史 FIM 用量记录会保留。

## 隐私与兼容性

需要 macOS 13 或更高版本，仅支持 Apple Silicon（arm64）。Cue 仅在用户触发 AI 重写时向所选 Provider 发送当前 prompt；若使用 `${message}`，仅会额外发送上述 Pi 文本快照。凭据不会写入 UserDefaults。

本版本使用 ad-hoc 签名，未经过 Apple 公证。请只从可信来源安装；若 macOS 阻止首次启动，请在“系统设置 → 隐私与安全性”选择“仍要打开”。

## 安装与校验

推荐在 Cask PR 合并后使用 Homebrew：

```bash
brew install --cask haotzops/tap/cue-notchpad
```

也可下载本 Release 中的 `Cue-Notchpad-0.4.0-macOS-arm64.zip`。将 ZIP 和 `SHA256SUMS` 下载到同一目录后运行：

```bash
shasum -a 256 -c SHA256SUMS
```

完整安装与配置说明见 [README](../../README.md)。
