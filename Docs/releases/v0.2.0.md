# Cue Notchpad v0.2.0

本版本完善编辑体验与分发验证。

## 主要更新

- **自定义编辑器字体**：在“设置 → 编辑器”中通过 macOS 原生字体面板选择字体和字号；设置会被记住，目标字体不可用时会安全回退到系统字体。安装并选择 Nerd Font 后，私有区图标字符可正常显示。
- **可选中英文间距**：可开启“提交时自动在中英文之间加空格”。它只会为相邻的中文与英文/数字补空格，不跨越标点、已有空白或换行，也不会在编辑、输入法组合或取消时改写内容。
- **Homebrew 安装体验**：Cask 安装完成后会自动移除 Cue Notchpad.app 的 quarantine 属性，减少未公证 app 的首次启动阻碍。
- **持续集成**：新增 macOS CI，验证源码、测试、原生 app、签名与 Universal 发布归档。

## 安装

推荐使用 Homebrew，它会同时安装 app 和 `cue` 命令：

```bash
brew install --cask haotzops/tap/cue-notchpad
```

也可下载本 Release 中的 Universal ZIP，将 `Cue Notchpad.app` 移到 `~/Applications`，并按照 [README 的 GitHub Release 安装说明](https://github.com/haotzops/cue-notchpad#github-release)创建 `cue` 启动脚本。

此版本使用 ad-hoc 签名，未经过 Apple 公证。Homebrew 安装会自动移除该 app 的 quarantine 属性；手动安装时，请只在确认下载来源可信后，前往“系统设置 → 隐私与安全性”选择“仍要打开”。

## 校验

将 ZIP 和 `SHA256SUMS` 下载到同一目录后运行：

```bash
shasum -a 256 -c SHA256SUMS
```
