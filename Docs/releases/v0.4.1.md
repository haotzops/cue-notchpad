# Cue Notchpad v0.4.1

本版本是维护性补丁版本，不改变 Cue Notchpad 应用功能。

## 修复

- Homebrew Cask 改用 Homebrew 当前推荐的 `postflight_steps`，消除安装时的 `postflight` 弃用警告。
- 保留安装完成后移除应用 quarantine 属性的行为，避免未公证应用首次启动时被 Gatekeeper 阻止。

## 兼容性

需要 macOS 13 或更高版本，仅支持 Apple Silicon（arm64）。

## 安装与校验

推荐使用 Homebrew：

```bash
brew install --cask haotzops/tap/cue-notchpad
```

也可下载本 Release 中的 `Cue-Notchpad-0.4.1-macOS-arm64.zip`，并使用随附的 `SHA256SUMS` 校验下载内容：

```bash
shasum -a 256 -c SHA256SUMS
```

完整安装与配置说明见 [README](../../README.md)。
