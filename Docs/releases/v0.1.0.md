# Cue Notchpad v0.1.0

Cue Notchpad 的首个公开预览版本。它可以作为 Pi、Codex、OpenCode 等命令行工具的外部 prompt 编辑器，并通过 `cue --wait` 等待编辑完成。

## 主要功能

- 依附于屏幕顶部 notch 的原生 macOS 编辑面板。
- 支持标准 `$EDITOR` / `$VISUAL` 文件接口和 stdin/stdout 接口。
- 支持多个并发编辑会话及调用方识别。
- 支持英文和简体中文。
- 内置离线 `cl100k_base` token 计数。
- 支持 Apple Silicon 和 Intel，最低要求 macOS 13。

## 安装

推荐使用 Homebrew，它会同时安装 app 和 `cue` 命令：

```bash
brew install --cask haotzops/tap/cue-notchpad
```

也可以下载本 Release 中的 Universal ZIP，将 `Cue Notchpad.app` 移到 `~/Applications`，再按照 [README 的 GitHub Release 安装说明](https://github.com/haotzops/cue-notchpad#github-release)创建 `cue` 启动脚本。

此预览版本使用 ad-hoc 签名，未经过 Apple 公证。macOS 可能阻止首次启动。请只在确认下载来源可信后，前往“系统设置 → 隐私与安全性”选择“仍要打开”。

## 校验

将 ZIP 和 `SHA256SUMS` 下载到同一目录后运行：

```bash
shasum -a 256 -c SHA256SUMS
```
